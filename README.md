# 菠萝岛鉴定助手

独立于「菠萝岛传说天气计算器」的手机优先 PWA。页面仍为静态文件，全员统计使用 Netlify Function 与 Netlify Blobs。

公开站点：https://velvety-cannoli-b8514a.netlify.app/  
源码仓库：https://github.com/yukisuki0210/pineapple-appraisal-helper

当前版本提供「当前鉴定 / 下一张预测 / 历史统计」三个页面。每行记录所选左、中、右位置、蓝/红牌和倍率；三项选齐后自动记录，并即时计算总倍率和收手预计收益。重置本局会保留历史记录，撤销上一条会从历史统计中移除该条。完整记录保存在当前设备；行数、位置和牌色默认匿名上传，汇入全员统计。基础价值、倍率和账号信息不上传。旧设备的有效本机历史会在打开新版页面后同步；离线时保留本地记录，恢复网络后重试。

当前鉴定页先输入果子基础价值，单位为“万”：输入 `2.5` 代表 `2.5万`，预计收益和收益试算也按“万”显示。已有版本保存的基础金额会按原数值除以 10000 后显示，保持原有金额不变。待选行的历史样本推荐直接显示在当前鉴定页，详细的三个位置出蓝率仍可在「下一张预测」中查看。

下一张页面优先按**全员匿名样本中同一行、同一位置**的历史记录计算出蓝率和样本量，并展示历史样本推荐位置；全员数据暂不可用时明确退回本机样本。任一位置少于 5 条记录时提示“样本不足，仅供参考”。全员数据是玩家自行录入的已选位置，可能有选择偏差、重复或错误，不能预测随机翻牌结果。历史统计页分别展示全员和本机记录。基础牌色规则保持不变：前 3 行 2 蓝 1 红，第 4 行起 1 蓝 2 红。旧版只有倍率的本局记录会保留，但因缺少位置与牌色，不纳入出蓝率统计。

原有玩家经验策略和收益试算仍保留在折叠区。

Netlify 从 `main` 分支构建：`node build.mjs`，发布目录 `dist`。构建会按网站文件内容生成新的离线缓存版本。全员统计由 `netlify/functions/shared-stats.mjs` 提供，依赖 `@netlify/blobs`；每条匿名记录使用独立键，避免并发写入覆盖汇总。Netlify Blobs 使用站点级存储，后续部署会保留数据。

本地预览：先运行 `node build.mjs`，再用静态文件服务器从 `dist` 目录预览。PWA 安装与离线功能需要 HTTPS 或 localhost。
