# 菠萝岛鉴定助手

独立于「菠萝岛传说天气计算器」的手机优先静态 PWA。

公开站点：https://velvety-cannoli-b8514a.netlify.app/  
源码仓库：https://github.com/yukisuki0210/pineapple-appraisal-helper

当前版本提供「当前鉴定 / 下一张预测 / 历史统计」三个页面。每行记录所选左、中、右位置、蓝/红牌和倍率；三项选齐后自动记录，并即时计算总倍率和收手预计收益。重置本局会保留历史记录，撤销上一条会从历史统计中移除该条。记录仅保存在当前设备的浏览器中，不上传服务器。

下一张页面只按**同一行、同一位置**的历史记录计算出蓝率和样本量，并展示历史样本推荐位置。任一位置少于 5 条记录时提示“样本不足，仅供参考”。历史选择可能有偏差，也不能预测随机翻牌结果。基础牌色规则保持不变：前 3 行 2 蓝 1 红，第 4 行起 1 蓝 2 红。旧版只有倍率的本局记录会保留，但因缺少位置与牌色，不纳入出蓝率统计。

原有玩家经验策略和收益试算仍保留在折叠区。

Netlify 从 `main` 分支构建：`node build.mjs`，发布目录 `dist`。构建会按网站文件内容生成新的离线缓存版本，无需第三方依赖。

本地预览：先运行 `node build.mjs`，再用静态文件服务器从 `dist` 目录预览。PWA 安装与离线功能需要 HTTPS 或 localhost。
