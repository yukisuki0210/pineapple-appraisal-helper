# 菠萝岛鉴定助手

独立于「菠萝岛传说天气计算器」的手机优先 PWA。页面仍为静态文件，全员统计使用 Netlify Function 与 Netlify Blobs。

公开站点：https://velvety-cannoli-b8514a.netlify.app/  
源码仓库：https://github.com/yukisuki0210/pineapple-appraisal-helper

当前版本提供「当前鉴定 / 下一张预测 / 历史统计」三个页面。每行记录所选左、中、右位置、蓝/红牌和倍率；三项选齐后自动记录，并即时计算总倍率和收手预计收益。重置本局会保留历史记录，撤销上一条会从历史统计中移除该条。完整记录保存在当前设备；本局随机标识、行数、位置和牌色默认匿名上传，汇入全员统计并用于连续路径条件统计。基础价值、倍率和账号信息不上传。旧设备的有效本机历史会在打开新版页面后同步；离线时保留本地记录，恢复网络后重试。

每局最多 6 行。记录第 6 行后自动结束，不能继续进入第 7 行；撤销上一条后可以重新录入第 6 行。旧版已经保存的超过 6 行的本机记录不会被删除，但不再纳入全员统计。

本局累计出现第 2 张红色惩罚牌时也会自动结束，即使尚未到第 6 行。撤销最近一行后，若红牌数降到 1 张以下，可继续录入。已有本机记录在打开新版时也会按这两条上限规则结束当前局。

当前鉴定页先输入果子基础价值，可选“元”或“万”：输入 `2500` 元，或切换后输入 `0.25` 万，都表示同一金额。切换单位时自动换算输入值；收手预计收益按金额大小显示为元或万。已有版本按“万”保存的数值及其单位继续保留；早期按“元”保存的数值也按原金额显示。待选行的历史样本推荐直接显示在当前鉴定页，详细的三个位置出蓝率仍可在「下一张预测」中查看。

下一张页面按本局已录入的完整路径筛选历史局，例如“第 1 行左蓝”后分别查看第 2 行左、中、右的出蓝率和样本量。推荐优先使用完整路径；当其中至少两个位置各有 5 条记录时便在这组条件样本中比较，其余样本不足的位置不参与。只有可比位置不足时才退回上一行条件，再不足时退回同一行总体。卡片与推荐始终使用同一组样本，依据会明确显示。位置排序使用历史出蓝率的 Wilson 保守下界，减少少量样本恰好全蓝造成的误导；展示的百分比仍是原始历史出蓝率。全员数据不可用时退回本机历史。新版通过匿名本局标识关联记录；旧版未关联的全员单行样本要等用户打开新版后才能参与路径统计。玩家自行录入的已选位置可能有选择偏差、重复或错误，条件历史频率不能预测随机翻牌结果。历史统计页分别展示全员和本机单行记录。基础牌色规则保持不变：前 3 行 2 蓝 1 红，第 4 行起 1 蓝 2 红。旧版只有倍率的本局记录会保留，但因缺少位置与牌色，不纳入出蓝率统计。

玩家经验策略仍保留在折叠区。单独的收益试算已移除，当前页直接显示收手预计收益。

Netlify 从 `main` 分支构建：`node build.mjs`，发布目录 `dist`。构建会按网站文件内容生成新的离线缓存版本。全员统计由 `netlify/functions/shared-stats.mjs` 提供，依赖 `@netlify/blobs`；每条匿名记录使用独立键，避免并发写入覆盖汇总。Netlify Blobs 使用站点级存储，后续部署会保留数据。

本地预览：先运行 `node build.mjs`，再用静态文件服务器从 `dist` 目录预览。PWA 安装与离线功能需要 HTTPS 或 localhost。
